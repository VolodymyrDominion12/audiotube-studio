# 009 · План реалізації

**Спека:** [spec.md](spec.md)

## 1. Підхід

Алгоритм — у `transcript.py`, як чиста функція в три проходи:

1. **Поділ тексту сегмента.** Текст сегмента розбиваємо на «фрази» за SUB-R4: речення, потім розділові знаки,
   потім слова. Жадібно збираємо фрази в титри, поки титр уміщається в `max_lines × max_chars` **і** його
   пропорційна тривалість ≤ `max_cue_seconds`. Фраза, що сама не вміщається, ріжеться на нижчому рівні пріоритету.
2. **Розкладка рядків.** Для кожного титра перебираємо всі розриви між словами (їх мало) і беремо найкращий
   за SUB-R5: мінімальна різниця довжин, бонус розриву після розділового знака, якщо баланс гірший ≤ 30 %.
3. **Вирівнювання часу.** Один прохід по всіх титрах: `min_cue_seconds`, подовження «щільних» у тишу (SUB-R3),
   закриття пауз < 0.3 с (SUB-R6), обрізання до наступного титра, лічильник `dense`.

Час усередині сегмента, як і зараз, ділиться пропорційно символам (SUB-R7).
Альтернатива — оптимальний поділ динамічним програмуванням — відкинута: жадібний варіант з пріоритетом
розділових знаків дає ту саму якість на мовленні й значно простіший.

Параметри збираємо в `SubtitleRules` (frozen dataclass) з `cfg.transcribe`, щоб не протягувати п'ять аргументів
через `transcribe.py` і `pipeline.py`. Публічні `build_cues(...)` і `write_srt(...)` зберігають сигнатури
(SUB-AC9); нова `layout_cues(segments, rules, duration) -> CueLayout(cues, dense)` повертає ще й лічильник.

## 2. Зміни по модулях

| Модуль | Зміна | Вимоги |
|--------|-------|--------|
| `audiotube/transcript.py` | `SubtitleRules`, `CueLayout`, `layout_cues`; `build_cues`/`write_srt` — обгортки | R1–R9 |
| `audiotube/config.py` | `transcribe.max_cue_seconds`, `min_cue_seconds`, `max_cps` + перевірка min < max | R1–R3 |
| `audiotube/transcribe.py`, `pipeline.py` | `SubtitleRules.from_config(cfg)`; журнал «щільних» | R10 |
| `audiotube/subtitles.py` (новий) | `rebuild_subtitles(cfg, db, ids, force, dry_run)` → звіт; `.bak` | R11–R15 |
| `audiotube/cli.py` | команда `subtitles` | R11–R15 |
| `tests/test_transcript.py`, `tests/test_subtitles_cmd.py` | AC1–AC14 | — |
| docs/04, `config.example.yaml`, README | нові ключі й команда | — |

## 3. Дані

Без міграцій. Нові ключі конфігу з дефолтами: `max_cue_seconds: 7.0`, `min_cue_seconds: 1.0`, `max_cps: 17`.
`jobs.subtitles` оновлюється командою, якщо шлях був порожній.

## 4. Ризики й відкат

- Зміна вигляду субтитрів для нових транскрипцій. Відкат без коду: `max_cue_seconds: 15`, `max_cps: 30`,
  `min_cue_seconds: 0.8` дають поведінку, близьку до поточної.
- `--force` над вручну відредагованим SRT — захищено `.bak` (SUB-R12).
