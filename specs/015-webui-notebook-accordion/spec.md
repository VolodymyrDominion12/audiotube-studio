# 015 · «Ноутбуки»: акордеон із лінивим завантаженням переказів

**Статус:** implemented · **Версія:** 1.0 · **Дата:** 2026-11-28
**Залежить від:** 008, 011 · **Модулі:** `webui.py`

## 1. Проблема

У базі вже 97 ноутбуків і 241 переказ. Список ноутбуків — таблиця з посиланнями: щоб побачити
перекази, треба піти на окрему сторінку й повернутися назад, втративши місце в списку. Око
чіпляється за довгу таблицю, а лічильники й перекази живуть на різних екранах.

## 2. User stories

- **US1** Як автор, я хочу бачити всі ноутбуки одним компактним списком із лічильниками, щоб
  швидко знайти потрібний.
- **US2** Як автор, я хочу розгорнути ноутбук на місці й одразу побачити його перекази, не
  втрачаючи решту списку.
- **US3** Як автор, я хочу шукати ноутбук за назвою та фільтрувати за станом (у черзі, помилки,
  опубліковані, без переказів), щоб не гортати все.
- **US4** Як автор, я хочу поділитися посиланням на конкретний розгорнутий ноутбук і повертатися
  кнопкою «Назад» до попереднього стану.

## 3. Поза межами

- Нові ендпоінти, таблиці БД або міграції: використовуємо наявні `GET /api/notebooks` і
  `GET /api/notebooks/<id>`.
- Пагінація та нескінченний скрол: пошук і фільтр на клієнті.
- Зміна головної сторінки черги (spec 011) і дії над задачами зі сторінки ноутбуків.
- Редагування переказів, аудіо-плеєр і кнопки рендеру/публікації всередині акордеона.

## 4. Функціональні вимоги

| ID | Вимога |
|----|--------|
| NB2-R1 | `/notebooks` показує ноутбуки як акордеон: кожен рядок — кнопка з назвою, лічильниками (скачано / у черзі / на YouTube / помилки / зникли / без аудіо) і датою синку. |
| NB2-R2 | Клік по згорнутому ноутбуку робить `GET /api/notebooks/<id>` і показує перекази inline під рядком; повторний клік згортає без запиту. Одночасно відкритий лише один ноутбук: відкриття іншого згортає попередній. |
| NB2-R3 | Вміст розгорнутого ноутбука — та сама інформація, що була на `/notebooks/<id>`: назва й дата переказу, стан артефакту (зник / аудіо видалено / відсутнє), тривалість, статус задачі та `#id`, посилання на YouTube, перший рядок помилки. Додається посилання «відкрити в NotebookLM». |
| NB2-R4 | URL відображає відкритий ноутбук: `/notebooks/<id>`; закриття повертає `/notebooks`. Прямий перехід за URL відкриває цей ноутбук, кнопки «Назад»/«Вперед» синхронізують стан без перезавантаження. |
| NB2-R5 | На сторінці є пошук за назвою (без урахування регістру) і фільтр «усі / у черзі / помилки / опубліковані / без переказів». Обидва працюють на клієнті, без запитів до сервера; показується «Показано X з Y». |
| NB2-R6 | Відповідь `GET /api/notebooks/<id>` кешується в памʼяті сторінки; повторне відкриття не робить запиту. Після синку кеш скидається, а відкритий ноутбук перечитується. |
| NB2-R7 | Завантаження переказів і помилка мають явні стани. Помилка не ламає сторінку: показується текст і кнопка «Повторити». |
| NB2-R8 | Нові ендпоінти не додаються; усі GET-запити, як і раніше, не змінюють БД (spec 008 WEB-R6). |

## 5. Нефункціональні вимоги

- Без нових залежностей: ванільний JS і той самий `http.server`.
- 97 ноутбуків рендеряться одним `innerHTML` без помітної затримки; перекази вантажаться лише
  для відкритого ноутбука.
- Клавіатура: заголовок акордеона — справжня `<button>` з `aria-expanded` і `aria-controls`,
  тіло — `role="region"`.
- Інтерфейс українською (конституція IX).

## 6. Інтерфейси

Нових інтерфейсів немає. Використовуються:

```
GET /notebooks              → HTML з акордеоном
GET /notebooks/<id>         → той самий HTML; JS відкриває ноутбук із URL
GET /api/notebooks          → список ноутбуків із лічильниками
GET /api/notebooks/<id>     → ноутбук + перекази (ліниве завантаження)
```

## 8. Відповідність конституції

- **II (стан у SQLite)** — акордеон лише читає наявні `notebooks`/`artifacts`; кеш у памʼяті
  сторінки не є джерелом істини й скидається після синку.
- **VI (обережність)** — нових записів у зовнішні сервіси немає; розгортання не запускає синк.
- **VII (тести без мережі)** — перевіряємо HTML-маркери й наявний API на `FakeAdapter`.
- **IX (українська)** — усі підписи, стани й повідомлення українською.
